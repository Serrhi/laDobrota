# Исследование для сайта La Dobrota

Здесь лежат отчёты по сайтам-примерам и материалы по стилю. Сам сайт в эту папку не попадает.

## Структура

- `sites/` — по одному отчёту на каждый сайт-пример (`sites/<название-сайта>.md`)
- `brand/` — логотип и заметки по стилю (цвета, шрифты, настроение)
- `summary.md` — сводка: какие приёмы берём в сайт La Dobrota и почему

## Что фиксируется в отчёте по сайту

1. Ссылка и что это за сайт
2. Структура страниц и навигация
3. Визуальный стиль: цвета, шрифты, фото, отступы
4. Удачные приёмы, которые стоит перенять
5. Что не подходит (и почему)

## Условия проекта

- La Dobrota — фиктивная фирма (школьный предмет)
- На сайте нет оплаты и продажи
- Сайт должен открываться ровно по тому адресу, который зашит в QR-код на визитке
