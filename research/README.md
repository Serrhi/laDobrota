# Исследование для сайта La Dobrota

Здесь лежат отчёты по сайтам-примерам и материалы по стилю. Сам сайт в эту папку не попадает.

## Содержание

- [`summary.md`](summary.md) — сводка: какие приёмы берём, какие будут страницы и интерактив, чего ещё не хватает
- [`katalog.md`](katalog.md) — каталог: 16 сыров с ценами, странами, аллергенами и описаниями; в конце — что проверить
- [`sites/cheesehouse.md`](sites/cheesehouse.md) — отчёт по cheesehouse.cz
- [`sites/krasolesi.md`](sites/krasolesi.md) — отчёт по krasolesi.cz
- [`sites/coca-cola.md`](sites/coca-cola.md) — отчёт по coca-cola.com/cz/cs (ориентир по подаче)
- [`brand/README.md`](brand/README.md) — логотип, цвета, шрифты, контакты и адрес из QR-кода
- `sites/img/` — скриншоты сайтов-примеров
- `brand/*.svg` — логотип в четырёх вариантах

## Условия проекта

- La Dobrota — фиктивная фирма (школьный предмет)
- На сайте нет оплаты и продажи
- Сайт должен открываться ровно по адресу из QR-кода на визитке: `https://ladobrota.pages.dev/`
