# Бренд La Dobrota — что взято с визитки

Источник: PDF визитки (2 страницы, сделана в Canva). Первая страница — логотип, вторая — контакты и QR-код.

## Адрес сайта

QR-код на визитке ведёт на **`https://ladobrota.pages.dev/`**. Сайт обязан открываться ровно по этому адресу.

Сейчас по этому адресу отдаётся `index.html` из корня ветки `main` этого репозитория (хостинг Cloudflare Pages). Значит, главная страница сайта должна лежать в корне репозитория как `index.html`.

## Логотип

Все файлы — векторные, вырезаны из первой страницы визитки без перерисовки.

| Файл | Что в нём | Где использовать |
| --- | --- | --- |
| `logo-full.svg` | сыр + надпись + пчёлы, прозрачный фон | подвал, заставка, контакты |
| `logo-full-black.svg` | то же на чёрной плашке | там, где фон не чёрный (превью для соцсетей) |
| `logo-mark.svg` | только головка сыра, без надписи | шапка, иконка вкладки, главный герой первого экрана |
| `logo-wordmark.svg` | надпись «LA DOBROTA SÝRÁRNA» с пчёлами | там, где сыр уже есть рядом |

Про «убрать надпись»: в шапке и на первом экране лучше работает знак без надписи (`logo-mark.svg`) — название рядом набирается текстом и остаётся читаемым на телефоне. Полный логотип с надписью остаётся в подвале.

## Шрифты

На визитке использованы **The Seasons** (Light, Regular) и **Dream Avenue** — это платные шрифты из Canva, на сайт их ставить нельзя без лицензии. Надпись «LA DOBROTA» поэтому берётся из логотипа как картинка, а не набирается заново.

Для сайта — бесплатные шрифты Google Fonts с чешской диакритикой:

- **Cormorant Garamond** (Light, Regular, Italic) — заголовки. Тонкая контрастная антиква, ближайшая бесплатная замена The Seasons.
- **Manrope** (Regular, SemiBold, Bold) — текст, меню, кнопки.
