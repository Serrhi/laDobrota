# Сводка: какой будет сайт La Dobrota

Макет: https://claude.ai/artifact/44Fw4d77txCpepFYp9YjJ2 (ссылка приватная, открывается только у владельца, пока не включён общий доступ).

## Условия

- Адрес: `https://ladobrota.pages.dev/` — он зашит в QR-код на визитке.
- Нет продажи и оплаты: ни корзины, ни цен, ни форм с личными данными.
- Многостраничный сайт с интерактивом.
- На ярмарке сайт открывают по QR-коду, то есть **с телефона** — мобильная версия главная.
- Язык сайта — чешский.

## Страницы

1. **Domů** — 3D-сыр с тремя золотыми точками (по нажатию — короткий факт о сыре), бегущая золотая строка, переключатель видов сыра, приглашение в квиз.
2. **Naše sýry** — 16 сыров из каталога ([`katalog.md`](katalog.md)) с фильтром по молоку; карточка переворачивается и показывает описание, страну, аллергены и цену. Корзины и оплаты нет.
3. **Náš příběh** — четыре шага производства, переключаются по нажатию; блок «Kdo jsme» с командой.
4. **Sýrový kvíz** — четыре вопроса, результат «Jsi Gouda / Manchego / karamelový sýr»; его показывают у стенда.
5. **Kontakt** — телефон, почта, адрес, Instagram, блок про ярмарку, карта.

## Интерактив

- 3D-сыр на главной: вращение, наклон за курсором, точки с фактами.
- Перевороты карточек сыров, фильтр.
- Пошаговая история производства.
- Квиз с результатом.
- Плавное появление блоков при прокрутке.

## Чего не хватает для сборки

- Ответы на вопросы по каталогу — список в конце [`katalog.md`](katalog.md).
- Фото сыров (сейчас карточки без фото).
- Команда: имена, должности, фото; название школы.
- Ярмарка: название, дата, место, номер стенда.
